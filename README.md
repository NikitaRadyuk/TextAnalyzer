# Text Analyzer Application

Приложение для анализа текста с использованием паттернов Composite и Chain of Responsibility.

## Описание

Приложение читает текст из файла, разбирает его на составные части (абзацы, предложения, лексемы, символы) и выполняет три операции:

1. **Подсчет букв и символов** в тексте
2. **Поиск предложений** с наибольшим количеством одинаковых слов
3. **Сортировка предложений** по частоте заданной буквы
4. **Замена первой и последней лексемы** в каждом предложении

## Технологии

- Java 11
- Maven
- JUnit 5
- Log4j2
